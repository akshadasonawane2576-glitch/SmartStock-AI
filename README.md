# 📦 SmartStock AI

**AI-Powered Inventory & Demand Intelligence System**

SmartStock AI is a business analytics application built using Python and Streamlit. It helps businesses analyze sales performance, monitor inventory, forecast product demand, and make data-driven decisions.

## 🚀 Features

- **Business Dashboard:** Track revenue, profit, sales trends, and top-selling products.
- **Data Upload:** Upload Sales and Inventory datasets in CSV or Excel format.
- **Smart Inventory:** Monitor stock levels and identify low-stock and out-of-stock products.
- **AI Demand Forecasting:** Predict future demand using a Random Forest Regression model.
- **AI Business Assistant:** Get answers to common business questions using a rule-based assistant.
- **Reports & Downloads:** Export business reports in CSV and Excel formats.
- **Dark & Light Theme:** Switch between display themes.

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Scikit-learn
- OpenPyXL

## ⚙️ How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Install the required libraries:

```bash
pip install -r requirements.txt
```

5. Run the application:

```bash
python -m streamlit run app.py
```

## 📊 Project Objective

To help businesses understand their sales performance, manage inventory efficiently, identify stock-related issues, and estimate future product demand through analytics and machine learning.
